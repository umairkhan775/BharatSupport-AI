# Bharat Support AI — Product Design System

## Product character

BSAI is a national citizen support service. The interface should feel calm, trustworthy, accountable, and built for real public service teams. Use contemporary Indian civic character through language coverage, clear service categories, and restrained saffron/green cues. Avoid flag motifs, tricolor gradients, government-seal imitation, ornamental monuments, and generic AI sparkle decoration.

## Visual language

- Warm paper canvas `#F5F5F0`, white work surfaces `#FFFFFF`, and deep botanical ink `#1C2925`.
- Forest green `#126A50` is the primary action and service-success color. Muted saffron `#DF8F39` is reserved for attention and civic warmth. Use brick `#A45A4B` only for escalations.
- Hairline borders `#E7E9E2` define surfaces. Use little or no shadow; depth comes from spacing, borders, and tonal surfaces.
- Use DM Sans for interface text and Manrope for display figures and headings. Headlines are compact, sentence case, and quietly confident.
- Use 8px increments for spacing. Surfaces have 8–10px corner radii; controls have 6–8px radii. Avoid pill-shaped everything.

## Layout and content

- Give each screen one clear title and one primary action. State the service context with concise labels and useful dates.
- Show operational data in a readable hierarchy: metric, explanation, then trend or status. Label illustrative/demo data honestly when it is not sourced from the API.
- Keep dashboards dense enough for operators without shrinking body text below 11px for secondary labels or 13px for core copy.
- Use semantic headings, buttons for actions, visible keyboard focus, and responsive navigation that remains usable on small screens.
- Use green for completed or healthy states, amber for pending attention, and brick for urgent human escalation. Never rely on color alone to convey a state.

## Motion and imagery

- Keep motion short and functional: hover, disclosure, and status changes only. Respect reduced-motion preferences.
- Prefer purposeful charts and real product content to 3D mascots, floating particles, glassmorphism, decorative emoji, and glowing gradients.
- Charts must include labels, a legend, and clear scales. If live data is unavailable, show a restrained fallback rather than implying precision.

## Avoid

- Default SaaS dashboard cards with excessive gradients, blur, glow, and oversized rounded corners.
- All-caps copy used as a substitute for hierarchy, tiny text, invented live activity, and unlabeled metrics.
- Unsupported promises about security, uptime, AI resolution, official status, or data coverage.
